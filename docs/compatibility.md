# 兼容范围

当前目标宿主：**DSH 0.2.1-rc.2**。目录收录量、静态检查和运行检查是不同概念；没有逐个运行整个市场，也不宣称所有条目兼容。

| 格式或来源 | 当前处理方式 |
| --- | --- |
| 内置外观与 `.omd-skin.json` v1 | 保留布局、配色、背景、高级外观能力 |
| `dsh-theme-plugin/v1` | 原生令牌、包内 CSS/资源、图片/视频背景、可选客户端 |
| Skin Center v2 | 样式、补丁、预览、背景、v1alpha1 hooks 与语义表面适配 |
| DSH ModuleLoader 客户端主题 | 依赖检查、独立模块身份、受控生命周期与隔离预检 |
| Deep Whale | 包内资源路由、customization v1/v2、原有偏好与时段规则 |
| Dream Skin v1 交换包 | 配色导入；该格式本身不包含完整动态主题 |
| 已安装原生主题 | 识别并纳入管理，继续由 DSH 原生插件管理器启停 |
| 需要额外后台业务服务的主题 | 需要服务适配或已有原生插件联动；不自动执行任意 Node 主入口 |

## 已检查的代表样本

开发环境为 macOS、隔离 DSH 0.2.1-rc.2 与 Chromium。以下结果不代表 Windows/Linux、所有交互状态或第三方插件组合已验证。

| 样本 | 结果 |
| --- | --- |
| 冰蓝气泡玻璃（Workshop / frutiger-aero） | 真实下载安装、壁纸/玻璃/配色显示、切换恢复通过 |
| 蓝色幻想（Workshop） | 动态 hooks 隔离加载、明暗切换、卸载、重挂载通过 |
| Open Sea 1.2.5 | 静态资源路由映射后通过隔离生命周期检查；设备上的 WebGPU 画面质量另受硬件能力影响 |
| Aqua 1.3.0 | 旧 store 模块路径适配后通过隔离生命周期检查 |
| Deep Whale / maid-atelier | 包内美术与 customization 接入后通过隔离生命周期检查 |
| Deep Whale / orca-link | 包内美术与 customization 接入后通过隔离生命周期检查 |
| 已安装 Glyph | 原生接管后保持单一画布；切换其他主题时正常停用 |
| 已有 v1 主题与自定义名称/标题 | 原选择、名称、标题迁移通过，原浏览器记录保持不变 |

整包已安装后的三页入口、真实预览图和市场浏览已验证；独立 CLI 与桌面版自带 CLI 的隔离检查入口均已验证。坏 JSON、缺少资源、越界路径和隐藏整个界面的 CSS 会被拒绝，启用失败/中断恢复有定点检查。

尚未完成 Windows/Linux 实机、Skin Center 整插件联动及完整 OMD 共装的交互验收。Skin Center 已安装状态采用原生联动保留其当前主题与设置，内部主题不会被无提示地批量复制。需要额外后台服务的作品，以及未逐项检查的长尾主题，不标记为完整兼容。

## 故障处理

不支持的格式、缺失资源、未知模块、隔离加载失败会阻断安装，并提供 AI 修复任务。启动或启用中断会恢复之前的选择；原包与用户设置保留。DSH 或适配器更新会使受影响的动态主题进入复检。

浏览器内的第三方主题仍具有普通主题脚本的页面权限。隔离预检是兼容故障检查，不是恶意代码安全证明，也无法穷尽延迟触发问题。只使用可信来源的主题。
