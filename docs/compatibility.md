# 兼容范围

[English](compatibility_EN.md)

当前支持 **DSH 0.2.1-rc.2**。以当前宿主的真实接口为准；目录中的旧快照会先查找同包、同仓库的新版，不恢复已经移除的宿主接口。

## 安装时自动完成

| 主题形式 | 自动处理 |
| --- | --- |
| 内置外观、`.omd-skin.json` v1 | 保留布局、配色、背景与高级外观能力 |
| `dsh-theme-plugin/v1` | 令牌、包内 CSS、图片／视频背景、可选动态客户端 |
| Skin Center v2 | 样式、补丁、预览、背景与 v1alpha1 hooks |
| DSH ModuleLoader 主题 | 保留完整程序、闭包和私有模块；映射资源并管理生命周期 |
| 有源码、缺少客户端构建的包 | 自动编译 JS／TS／JSX 与声明依赖，不运行上游安装脚本 |
| 有后台入口的 DSH 主题 | 在真实 Cordis 子上下文中运行，使用当前宿主的 RPC、HTTP 和配置服务 |
| Deep Whale | 原始美术、customization v1/v2、偏好与时段规则 |
| Dream Skin v1 交换包 | 导入该格式实际提供的配色；完整动态插件走 DSH 主题安装流程 |
| 已安装的原生主题 | 自动发现并通过 DSH 原生管理器协调启停，保留原配置 |

下载固定到版本或提交。源码包不完整时，可核对同包、同版本、同仓库的 npm 发行包。选中的新版未通过检查时，还会检查目录原版本；只有它能通过当前 DSH 的同一套检查才会回退安装。不会为提高兼容数量丢弃动态功能或伪造服务响应。

主题包下载上限为 256 MiB，解压资源上限为 512 MiB／6,000 个文件；本地文件导入上限为 80 MiB。原始包文件保留，编译和适配结果单独保存。

## 检查覆盖什么

动态主题在独立 DSH profile 与独立浏览器中检查：页面加载、实际输入、设置入口、明暗切换、客户端卸载／重挂载、后台停止／恢复，以及再次打开页面。具有原生可编辑 Config 表单的主题还检查配置写入。每个候选使用自己的宿主，坏主题不能污染下一个候选。

需要修改启动 HTML 的主题会自动刷新以完成切换；存在未发送草稿或附件时延后刷新。安装失败保留原外观，启用失败恢复之前的选择。宿主或适配器更新后重新检查受影响主题，保留主题库和配置。

2026-10-20 的批量检查采用 **549 个去重目录条目**的固定快照，逐条准备并对可运行候选检查真实宿主；公共修复后复查受影响主题，最终 **454 个通过基础运行检查，95 个未放行**。失败项包含过老主题、无法准备的来源、资源缺失和运行问题，未作为已兼容条目。市场实时数量会变化，目录收录与通过检查不是同一指标。

| 代表作品 | 已验证内容 |
| --- | --- |
| dsh-ads 0.1.3 | 真实市场下载、安装应用、明暗、原生输入／设置、卸载和重挂载 |
| 虎鲸链路 0.0.1 | 真实市场安装、原始美术资源、切换和恢复 |
| Dream Skin 10.20.0 | 当前宿主加载、原生后台接口及生命周期 |
| 哥伦比娅 / dsh-columbina-theme | 原生设置写入、校验、停用重启后持久化 |
| Open Sea、Catppuccin、Deep Whale 系列 | 在对应固定候选上检查资源与客户端／后台生命周期 |

安装包已通过 DSH 原生安装器；在 macOS 隔离环境中与 OMD／OpenCU 共装，验证单一外观入口和三个子页。以上不代表所有附加功能、长时间运行、设备图形能力或第三方插件组合均已验证。Windows／Linux 尚无实机验收。

## 仍会阻止安装的情况

- 只支持过老 DSH、需要已移除模块或服务，且没有可用的当前宿主版本。
- 上游包缺图片、代码或必要资源，无法从匹配的正式发行包补全。
- 加载、保存设置、重新打开页面失败，或主题使输入／设置不可用。
- 依赖尚未准备的本地辅助服务，或资源下载／检查环境不可用。

错误会给出具体原因与可复制的 [AI 修复任务](ai-repair.md)。字体文件不可用但主题声明了浏览器回退时，会保留回退并显示提示；必要图片、脚本和后台接口失败仍然阻止安装。

第三方主题仍是插件，后台具有正常 Node／DSH 插件能力，浏览器脚本具有页面权限。独立 profile 用于发现兼容故障，不是恶意代码安全沙箱，也无法穷尽延迟触发问题。使用可信作者的主题。
