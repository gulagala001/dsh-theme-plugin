# 支持哪些主题

[English](compatibility_EN.md) · [返回首页](../README.md)

当前适配 **DSH 0.2.2-rc.3**。主题按这个版本的 DSH 来检查；市场里的旧版本会先去找同一个包、同一个仓库的新版，不会为老主题补回 DSH 已经删掉的接口。

## 安装时自动处理

| 主题形式 | 处理方式 |
| --- | --- |
| 内置外观、`.omd-skin.json` v1 | 保留布局、配色、背景和高级外观设置 |
| `dsh-theme-plugin/v1` | 配色变量、包内 CSS、图片或视频背景、可选的动态脚本 |
| Skin Center v2 | 样式、补丁、预览、背景和 v1alpha1 hooks |
| DSH ModuleLoader 主题 | 完整保留主题程序，处理资源路径，负责启动和卸载 |
| 只有源码、没打包前端的主题 | 自动编译 JS、TS、JSX 和声明的依赖，不运行上游的安装脚本 |
| 带后台的 DSH 主题 | 后台在 DSH 里正常运行，用当前 DSH 的接口和配置 |
| Deep Whale | 原始美术、customization v1/v2、偏好和时段规则 |
| Dream Skin v1 交换包 | 导入它包含的配色；完整的动态插件走普通主题安装 |
| 已经装好的主题插件 | 自动找到，由 DSH 自己的插件管理开关，原配置不动 |

下载会固定到具体版本或提交。源码包不完整时，会用同包、同版本、同仓库的 npm 发行包补齐。新版没通过检查时，会再试市场里记录的原版本，原版本也要通过同样的检查才会装。不会为了多装几个主题而删掉动态效果或伪造接口返回。

| 限制 | 上限 |
| --- | --- |
| 主题包下载 | 256 MiB |
| 解压后 | 512 MiB，最多 6,000 个文件 |
| 本地导入文件 | 80 MiB |

原始主题包会原样保留，编译和适配的结果单独存放。

## 试跑检查什么

动态主题在单独的 DSH profile 和单独的浏览器里试跑：加载页面、输入文字、打开设置、切换明暗、卸载再装回、停止并恢复后台、重新打开页面。主题带设置表单的，还会试着保存一次设置。每个主题用自己的一套环境试跑，一个坏主题不会影响下一个。

有的主题需要改启动页面，切换时会自动刷新；输入框里有没发出的草稿或附件时，会等你发完再刷新。安装失败时外观不变，启用失败时回到之前的选择。插件或 DSH 更新后，受影响的主题会重新检查，主题库和设置都保留。

移除当前正在用的主题时，会先换回 DSH 原生外观，再停掉它的后台。

## 哪些情况装不上

- 主题只支持很老的 DSH，用到了已经删除的模块或服务，而且没有适配当前 DSH 的版本。
- 主题包缺图片、代码或必要资源，也没有匹配的正式发行包可以补。
- 加载、保存设置或重新打开页面失败，或者主题让输入框、设置页没法用。
- 主题要用一个本机还没准备好的辅助服务，或者下载、试跑环境不可用。

装不上时会给出具体原因，并提供可复制的 [AI 修复任务](ai-repair.md)。字体文件下载不了、但主题写了备用字体时，会用备用字体并提示你；必需的图片、脚本和后台接口出错仍然会阻止安装。

## 市场来源

[DSH 皮肤市场](https://kingofsoysauce.github.io/dsh-skin-market/)、[创意工坊](https://dsh-market.com/)、[A2H](https://dsh.a2hmarket.ai/) 和 [DSH 社区目录](https://awesome-dsh-plugin.com/)。重复的主题会合并成一条；没有预览图的会标出来，某个来源连不上时显示缓存内容或"不可用"。

## 安全

第三方主题本质上是插件：后台能做普通 DSH 插件能做的事，页面脚本拥有页面权限。试跑用来发现兼容问题，不是防恶意代码的沙箱，也发现不了所有延迟才出现的问题。只装你信得过的作者的主题。
