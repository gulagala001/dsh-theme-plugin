# dsh-theme-plugin 0.1.0 · DSH 0.2.1-rc.2

## 中文

首个正式版本，在 DSH 中集中管理外观、已有主题和社区主题市场。

### 新增功能

- 设置 → 外观提供外观设置、主题管理、市场三个子页；内置六种外观与 29 套配色，支持背景、字体、尺寸、圆角、透明度和动态效果。
- 连接四个社区主题来源，展示图片、说明、作者和版本，支持搜索、风格筛选、来源合并与一键下载安装应用。
- 识别已有主题与可迁移偏好，支持文件导入导出、受支持动态主题及其专属设置。
- 安装前检查格式、资源、接口和隔离加载；启用失败或中断恢复之前的选择。不兼容主题可复制完整 AI 修复任务，修复包重新导入复检。
- 提供可选主题开发协议、模板、校验与打包命令；宿主差异集中适配，升级后重新检查受影响主题。

### 其他变更

- 安装包标识为 `@gulagala001/dsh-theme-plugin`，使用固定 GitHub Release 包；无作用域 npm 同名包属于其他作者。
- 当前支持 DSH **0.2.1-rc.2**。已有 macOS 隔离真实安装、图片市场、代表动态主题生命周期与故障恢复验证；Windows/Linux 实机、所有主题和插件组合尚未逐项验证。市场收录不等于全部兼容；后台服务型主题需明确服务适配或原生联动。

## English

The first release brings appearance controls, existing themes and community theme markets into DSH.

### New Features

- Three Appearance pages: settings, theme management and market. Six built-in appearances and 29 palettes cover backgrounds, typography, geometry, transparency and effects.
- Four community sources with images, descriptions, authors and versions, search/filtering, source deduplication and checked one-click installation.
- Discovery of existing themes and migratable preferences, file import/export, supported dynamic clients and theme-specific controls.
- Pre-install format, resource, interface and isolated-loading checks; failed or interrupted activation restores the previous selection. Copyable AI repair tasks and normal rechecks for repaired packages.
- Optional theme protocol, template, validation and packing commands. Centralized host adapters and revalidation after relevant host changes.

### Other Changes

- Package identity: `@gulagala001/dsh-theme-plugin`, distributed through a fixed GitHub Release archive. The unscoped npm name belongs to another author.
- Targets DSH **0.2.1-rc.2**. Real isolated installation, visual market, representative dynamic lifecycles and recovery checks were exercised on macOS. Windows/Linux devices, every theme and all plugin combinations have not been individually validated. Catalog inclusion is not compatibility; backend-dependent themes require explicit service adaptation or native linkage.

## 安装 / Installation

仅适用于 DSH **0.2.1-rc.2**、Cordis **4.0.5**、Node.js **22.19+**。打开 **插件 → ＋ 添加插件**，粘贴下方地址。保留原 profile 与数据，按宿主提示启用；需要重启时先结束当前任务。

For DSH **0.2.1-rc.2**, Cordis **4.0.5** and Node.js **22.19+**. Open **Plugins → Add Plugin** and paste the URL below. Retain your profile and data; finish active tasks before a requested restart.

```text
https://github.com/gulagala001/dsh-theme-plugin/releases/download/v0.1.0-dsh.0.2.1-rc.2/gulagala001-dsh-theme-plugin-0.1.0-dsh.0.2.1-rc.2.tgz
```
