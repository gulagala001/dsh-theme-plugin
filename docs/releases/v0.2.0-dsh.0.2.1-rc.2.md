# dsh-theme-plugin 0.2.0 · DSH 0.2.1-rc.2

## 中文

本次更新集中改进当前 DSH 的主题兼容、原生设置与安装恢复。已有 0.1.0 用户请安装本版固定包；主题库和配置保留，受影响主题会重新检查。

### 新增功能

- DSH 主题后台接入真实宿主服务，支持原生 RPC、HTTP 路由和可编辑配置；设置经过原生校验并持久保存。
- 市场旧条目自动检查同包、同仓库的可用新版；新版失败时，继续检查原目录版本，只有通过当前宿主检查才安装。
- 源码型主题自动准备客户端与后台依赖；不完整源码包可核对匹配的完整发行包。

### 体验优化

- 保留主题完整程序、私有模块、原始美术、字体和动态效果，减少需要手工修复的情况。
- 市场卡片区分待检查、旧条目和本机已通过检查；详情显示实际安装版本及回退来源。
- 需要刷新页面的主题自动完成切换；未发送草稿和附件会延后刷新。
- 更新中英文首页、安装指南、兼容说明和真实市场截图。

### 问题修复

- 修复原生安装器因构建依赖安装脚本拒绝安装的问题。
- 修复主题设置保存、配置更新作用域、后台 RPC 注册及部分品牌插槽冲突。
- 加强后台卸载、重新挂载和再次打开页面检查；逐个使用独立宿主，避免坏主题污染后续检查。
- 保留普通字体回退；必要图片、脚本、接口失败以及持续遮挡输入或设置的问题仍阻止安装。

### 其他变更

- 兼容以 **DSH 0.2.1-rc.2** 为准，不为过老主题重建已移除接口。
- 后台主题使用正常 Node／DSH 插件能力。独立 profile 预检用于兼容故障检查，不构成恶意代码安全沙箱。
- 已完成 macOS 原生安装及代表主题、配置和共装验证；批量检查范围见[兼容说明](https://github.com/gulagala001/dsh-theme-plugin/blob/main/docs/compatibility.md)。Windows／Linux 实机及全部附加功能尚未验证。

## English

This update focuses on current-host theme compatibility, native configuration and installation recovery. Existing 0.1.0 users should install this fixed release package. Theme files and configuration are retained; affected themes are rechecked.

### New Features

- Theme backends use real DSH services, including native RPC, HTTP routes and editable configuration with native validation and persistence.
- Stale market entries check newer releases with matching package/repository identity. If a newer candidate fails, the original catalog version must pass the same current-host checks before fallback installation.
- Automatic client/backend preparation for source themes and matching published artifacts for incomplete source packages.

### Improvements

- Preserve complete programs, private modules, original artwork, fonts and dynamic behavior, reducing manual repairs.
- Market cards distinguish unchecked, stale and locally checked entries. Details show the installed version and fallback source.
- Themes requiring a page refresh complete switching automatically, deferring refresh while unsent drafts or attachments remain.
- Updated bilingual overviews, installation guides, compatibility documentation and a real marketplace screenshot.

### Bug Fixes

- Remove the build-dependency installation script that caused DSH's native installer to reject the package.
- Fix native configuration persistence/update scopes, backend RPC registration and some brand-slot collisions.
- Check backend disposal, remount and reopening in an independent host per candidate, preventing failed themes from contaminating subsequent checks.
- Retain normal browser font fallback; missing required artwork/scripts/endpoints and persistent input/settings obstruction still block installation.

### Other Changes

- Targets **DSH 0.2.1-rc.2** without recreating removed APIs for obsolete themes.
- Backends retain normal Node/DSH plugin capabilities. Disposable-profile preflight checks compatibility faults, not malicious-code safety.
- Native installation, representative themes, configuration and coinstallation were exercised on macOS. See [compatibility coverage](https://github.com/gulagala001/dsh-theme-plugin/blob/main/docs/compatibility_EN.md). Windows/Linux devices and every additional feature remain unverified.

## 安装 / Installation

仅适用于 DSH **0.2.1-rc.2**、Cordis **4.0.5**、Node.js **22.19+**。打开 **插件 → ＋ 添加插件**，粘贴下方地址。保留原 profile 与数据；需要重启时先结束当前任务。

For DSH **0.2.1-rc.2**, Cordis **4.0.5** and Node.js **22.19+**. Open **Plugins → Add Plugin** and paste the URL below. Retain your profile and data; finish active tasks before a requested restart.

```text
https://github.com/gulagala001/dsh-theme-plugin/releases/download/v0.2.0-dsh.0.2.1-rc.2/gulagala001-dsh-theme-plugin-0.2.0-dsh.0.2.1-rc.2.tgz
```
